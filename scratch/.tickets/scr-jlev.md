# Create an appropriate gitignore and commit to git, making sure not to include extraneous files

## Plan

### 1. Update `.gitignore`

The existing `.gitignore` has three entries (`node_modules`, `dist`, `*.tsbuildinfo`). Add the following:

- `.playwright-cli/` — ephemeral browser automation session data (Playwright page captures), not project source
- Compiled config file artifacts that TypeScript composite builds emit outside `dist/`:
  - `*.config.js` pattern is too broad; instead target the specific generated files at package roots. A general pattern like `packages/*/vitest.config.js` and corresponding `.map`, `.d.ts`, `.d.ts.map` files will work. Alternatively, since these are tsc compilation artifacts from config files, we can simply not track them.

Final `.gitignore` should be:

```
node_modules
dist
*.tsbuildinfo
.playwright-cli
```

Note: The `vitest.config.{js,js.map,d.ts,d.ts.map}` files in `packages/api/` are generated by tsc composite builds. Since they sit alongside the source `vitest.config.ts`, they should also be ignored. We can handle these with a glob pattern or explicit entries. However, these are already effectively inside the `dist`-like output — they just happen to be emitted at the package root because the config file is at the root. A clean approach is to add:

```
# Compiled config artifacts (tsc composite output outside dist/)
*.config.js
*.config.js.map
*.config.d.ts
*.config.d.ts.map
```

But this could conflict if any source `.config.js` files exist. Since none do in this project, this is safe. Alternatively, be more targeted:

```
packages/*/*.config.js
packages/*/*.config.js.map
packages/*/*.config.d.ts
packages/*/*.config.d.ts.map
```
