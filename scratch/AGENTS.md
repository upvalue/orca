# Tickets

Ticketing system:

Tickets live in .tickets
`./ticket show scr-blwa` to see a ticket. 
`./ticket tag scr-blwa tag` to tag a ticket.
`./ticket untag scr-blwa tag` to remove a tag from a ticket.
You can edit ticket files directly if needed.
Use ./ticket --help for detailed help.

Tickets should be tagged with 'frontend' and 'backend' if they effect the frontend or the backend.
